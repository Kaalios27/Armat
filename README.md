# Armat

A personal study system for European Spanish (Castilian, with vosotros). One focused hour a day: vocabulary, conjugation and grammar, Monday to Saturday, and a 60-minute examination on Sunday. The system plans what to study, schedules revision with FSRS-7, tracks every answer, and adapts to weaknesses and exam results. The interface and all explanations are available in English (default) or French.

Architecture and design decisions: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## What it does

- **Daily session**: three 20-minute modules in fixed order, with server-side timing, pause and resume, and autosave.
  - Vocabulary: about 470 curated items (false friends, discourse markers, idioms, academic and professional vocabulary), recognition and typed, accent-sensitive production, cloze in context, and FSRS-7 scheduling with learning steps.
  - Conjugation: 29 units from the present to the pluperfect subjunctive, with a deterministic conjugator (about 120 verbs, all tenses, vosotros, reflexive imperatives with correct accents). Errors are classified as wrong person, wrong tense, ending, irregular verb, missing accent, stem change or missing pronoun.
  - Grammar: 56 concepts in nine chapters. The first 14 lessons and exercises are curated; later lessons and exercises are generated by the AI, validated, and stored.
- **Sunday exam**: dictation (15), conjugation (20), grammar (20), translation (15), writing (30). It is built from the week's history, failed items and weaknesses. Every fourth exam is cumulative (40% last four weeks, 40% older material, 20% weaknesses). Grading is deterministic where possible and uses the AI with a published rubric for open answers.
- **Learner model**: concept mastery (weighted accuracy), FSRS revision of concepts, decaying weaknesses, an adaptive new-word pace, and a level estimate from demonstrated competence.

## Run locally

Requirements: Node.js 24 or later.

```bash
npm install
cp .env.example .env.local   # optional; everything works without it
npm run dev
```

Without `DATABASE_URL`, an embedded PostgreSQL (PGlite) database is created in `.data/pglite`. Stop the dev server with Ctrl+C so it closes cleanly. Without `APP_PASSWORD`, access is open in development only.

```bash
npm test          # Vitest: conjugator, FSRS, scheduling, sessions, exams, AI error handling (PGlite)
npm run typecheck
npm run build
```

GitHub Actions runs the same three checks on every push to `main` and on pull requests (`.github/workflows/ci.yml`).

## Deploy (Vercel + Supabase)

GitHub Pages cannot run server code, so it cannot keep API keys secret. Deploy to Vercel from this repository.

1. **Database**: create a Supabase project. In *Project Settings > Database > Connection string*, copy the **Transaction pooler** URI (port 6543).
2. **Vercel**: import the GitHub repository. Set these environment variables:
   - `DATABASE_URL`: the Supabase URI.
   - `APP_PASSWORD`: your login password.
   - `SESSION_SECRET`: 32+ random characters (`node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"`).
   - `AI_PROVIDER=anthropic` and `ANTHROPIC_API_KEY` (from console.anthropic.com). Optional: `ANTHROPIC_MODEL` (default `claude-opus-5-5`).
   - Spending caps: `AI_DAILY_BUDGET_USD` (default 1.50), `AI_MONTHLY_BUDGET_USD` (default 20), `AI_MAX_CALLS_PER_MINUTE` (default 12).
   - Optional dictation voice: `TTS_PROVIDER=azure` with `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION`, or `TTS_PROVIDER=google` with `GOOGLE_TTS_API_KEY`. Without them, the device's es-ES voice is used.
3. **Build command**: set it to `npm run vercel-build`. This applies migrations, seeds the curated content (idempotent), then builds. Migrations also run automatically on first access.
4. Open the deployment and sign in.

OpenAI is supported as an alternative (`AI_PROVIDER=openai`, `OPENAI_API_KEY`, `OPENAI_MODEL`). The AI is never enabled unless `AI_PROVIDER` is set explicitly. When it is off or over budget, sessions continue on curated content; open exam answers are marked as pending instead of being guessed.

The Anthropic integration uses structured outputs validated with Zod, adaptive thinking, and server-side refusal fallback (`fallbacks: "default"`).

### How far the curated content goes without AI

| Area | Curated | Lasts about |
|---|---|---|
| Vocabulary | ~465 words | 4 to 6 weeks (18 new words per session at the standard pace) |
| Grammar | 14 of 56 lessons, with exercises | 3 to 5 weeks (one new concept at most per day, gated by mastery) |
| Conjugation | 29 units, drills generated by the conjugator | several months (mastery needs at least two sessions per unit) |

After that, new words and grammar lessons need the AI. Without it, sessions continue with revision of what has been introduced.

## Data

- Settings > Export downloads all your data as JSON.
- Supabase keeps daily backups of the database.
- Secrets live only in environment variables; `.env*` files are git-ignored.

## Notes

- The exam timer counts while the exam page is open; answers autosave to the server and the device. The exam is not cheat-proof, by design.
- With device speech synthesis, the dictation text is present in the page (base64) so the device can read it. With server speech, it stays on the server.
